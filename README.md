# Supplementary code and results: Metamorphic assurance of multi-view ECG feature pipelines

Code, released results and tables for the manuscript "Metamorphic Assurance of Multi-View ECG Feature Pipelines:
Silent Integration Faults, Monitoring Baselines and Fusion Fragility" (PTB-XL+, myocardial infarction vs normal).

- Repository: https://github.com/hembabu78github/multiview_ecg
- Archive: https://doi.org/10.5281/zenodo.23652627
- Version: tag v1.0.0 and v1.0.1 point to the same commit.
- Licence: Apache 2.0 (see `LICENSE`).

## Layout
| Path | Content |
|---|---|
| `code/` | pipeline, fault injection, monitors, analysis and verification scripts |
| `tests/` | unit tests (`pytest tests`) |
| `results/` | outputs regenerated by `reproduce.sh` and the released CSVs for the scripts not re-run |
| `results_as_released_v1.0.0/` | files as shipped in tag v1.0.0, for comparison |
| `review/clinician_verdicts_deidentified.csv` | de-identified cardiologist verdicts on the fault relations |
| `supplementary_tables/Supplementary_Tables_S1-S5.xlsx` | Tables S1-S5 (Online Resource 1) |
| `cohort_ids.csv` | the 11,603 record identifiers of the cohort |
| `make_waveforms.py` | downloads the 100 Hz PTB-XL waveforms (needs `wfdb` and network access) |
| `REPRODUCTION_REPORT.md` | what was re-run and what matched |
| `MANIFEST_sha256.txt` | SHA-256 of every file in this package |

## Data
The raw data are public on PhysioNet (PTB-XL and PTB-XL+) and are not included. Place these files in `data/`:
`ptbxl_database.csv`, `scp_statements.csv`, `feature_description.csv`, `12sl_features.csv`, `ecgdeli_features.csv`, `unig_features.csv`.

## Running
```
pip install -r requirements.txt        # Python 3.13; pinned versions
bash reproduce.sh                      # or: docker build -t mvecg . && docker run -v "$PWD/data:/work/data" mvecg
```
`reproduce.sh` runs, in order: `train_models.py`, `run_ext.py`, `monitors.py` (about 15 min on 2 cores),
`run_experiments.py --split test --B 2000`, `analyze.py test`, `verify.py test`, `verify_ext.py`, `pytest tests`,
and `accepted_only_rerun.py` for the variants `all23`, `notrejected` and `strict`. Use B=2000; the default B=1000 gives the same
detections but different bootstrap bounds. The path can be overridden with `MVECG_ROOT`.

Long-running scripts not run by `reproduce.sh` (released CSVs are in `results/ext`): `code/run_rot_all.sh` (ten-fold rotation),
`run_benign*.py` with `code/finalize_benign.sh` (benign retraining), `cost_timing.py`, and the decision-metric and abstention scripts.
